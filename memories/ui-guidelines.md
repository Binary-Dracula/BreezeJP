# Flutter UI 设计规范摘要

- 项目 UI 规范主入口：`.agents/skills/breezejp-ui-design/SKILL.md`
- 新增 Flutter 页面/组件时优先遵循该 Skill，而不是套用通用 UI 模板。
- 默认页面背景以 `#F6F7FB` 为主；文章/内容列表可用 `#F8FAFC`；阅读沉浸页可用 `#FDFBF7`。
- 主要语义色：品牌蓝 `#1E88E5`、学习蓝 `#5C8DFF`、阅读靛蓝 `#6366F1`、复习青绿 `#14B8A6`、成功绿 `#34D399`/`#22C55E`、语法紫 `#8B5CF6`/`#7C3AED`。
- 高频母版页面：`home_page`、`vocabulary_book_page`、`article_list_page`、`learn_page`。
