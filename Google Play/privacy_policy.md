# BreezeJP 隐私政策 / Privacy Policy

**生效日期 / Effective Date: 2026-04-26**

---

### 1. 信息收集与使用 / Information Collection and Use

- **中文**: 本应用致力于保护您的隐私。若您仅使用本地学习功能，我们不会要求您提供姓名、电话或地理位置等信息。若您主动注册或登录以使用云端同步与跨设备学习，我们会处理与账号相关的最小必要信息，例如邮箱地址、认证标识以及与学习同步直接相关的数据。
- **English**: This app is committed to protecting your privacy. If you only use local learning features, we do not require your name, phone number, or location. If you choose to register or sign in for cloud sync and cross-device learning, we process the minimum necessary account-related information, such as your email address, authentication identifier, and sync-related learning data.

### 2. 技术声明 / Technical Statement

- **中文**: 本应用同时包含本地能力与云端能力。假名标注、部分离线音频与设备内学习流程可在本地运行；新闻内容拉取、账号认证、学习进度同步与跨设备续接会通过我们的云端服务完成。云端同步所涉及的数据仅用于提供这些功能本身，不用于广告定向。
- **English**: This app includes both local and cloud-powered features. Furigana rendering, some offline audio capabilities, and on-device learning flows can run locally; news delivery, account authentication, learning progress sync, and cross-device resume rely on our cloud services. Data involved in cloud sync is used only to provide those features and is not used for ad targeting.

### 3. 云端同步数据 / Cloud Sync Data

- **中文**: 当您启用登录与同步后，我们可能存储您的单词、语法、假名学习状态，学习/复习会话快照与完成结果，书本进度，以及用于冲突处理和设备识别的同步元数据。这些数据会保存在 Supabase 数据库与 Cloudflare 提供的相关基础设施中，用于实现跨设备学习。
- **English**: When you enable sign-in and sync, we may store your word, grammar, and kana learning states, learning or review session snapshots and completion results, book progress, and sync metadata used for device identification and conflict handling. This data is stored in infrastructure provided by Supabase and Cloudflare to enable cross-device learning.

### 4. 第三方服务 / Third-party Services

- **中文**: 我们使用 Google Play 进行版本分发，并使用 Supabase 与 Cloudflare 提供认证、数据库、对象存储和 API 基础设施。这些服务可能处理必要的技术日志、认证信息或去标识化的稳定性数据，以保证服务可用性与安全性。
- **English**: We use Google Play for app distribution, and Supabase and Cloudflare for authentication, database, object storage, and API infrastructure. These services may process necessary technical logs, authentication information, or de-identified stability data to maintain service availability and security.

### 5. 核心功能与隐私承诺 / Core Features & Privacy Commitment

- **中文**: 本应用坚持**零广告**。部分功能可在不登录的情况下使用；涉及云端同步、跨设备学习和受保护在线内容的功能，则需要登录后才能使用。
- **English**: This app remains **zero ads**. Some features are available without signing in, while cloud sync, cross-device learning, and protected online features require an authenticated account.

### 6. 儿童隐私 / Children's Privacy

- **中文**: 本应用并非针对 13 岁以下儿童。如果您认为我们意外收集了此类信息，请联系我们。
- **English**: This app is not directed at children under 13. If you believe we have accidentally collected such info, please contact us.
